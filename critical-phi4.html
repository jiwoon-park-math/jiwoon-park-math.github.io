The critical two-point function of lattice φ⁴₂

Jiwoon Park

Manuscript PDF · LaTeX source on GitHub

Abstract

In this article, we show that the critical two-point correlation function of the lattice φ⁴₂ model in the strong coupling regime follows that of the Ising universality class.

Main theorem

Consider real spins on the square lattice with nearest-neighbor ferromagnetic interaction and single-site weight proportional to exp(−g(φ²−1)²). Write Gφ,β(x) for the infinite-volume free two-point function, βc(g) for the critical inverse temperature, and GI(x) for the critical nearest-neighbor Ising two-point function on the square lattice.

There exist g0 < ∞ and ω > 0 such that for every fixed g ≥ g0 there is Zφ(g) > 0 with Zφ(g) = 1 + O(g−1) and, uniformly as |x| → ∞,

Gφ,βc(g)(x) = Zφ(g)2 GI(x) + Og(|x|−1/4−ω).

In particular, the critical free two-point function is asymptotic to Cg|x|−1/4 for some Cg > 0.
