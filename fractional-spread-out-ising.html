Correlation function of the fractional spread-out Ising models at their upper critical dimension and critical temperature

Jiwoon Park

Manuscript PDF · LaTeX source on GitHub

Abstract

We give a renormalisation-group argument for the critical free two-point function of the spread-out Ising model with kinetic operator (−ΔR)d/4 in dimensions 1 ≤ d ≤ 4. For sufficiently large fixed spread radius R, the critical correlation is asymptotic to a positive constant times |x|−d/2.

Main theorem

For each d ∈ {1, 2, 3, 4} and all sufficiently large fixed spread radii R, consider the Ising model with kinetic operator (−ΔR)d/4, where ΔR is the spread-out Laplacian. At the critical inverse temperature τc(d, R), the infinite-volume free two-point function satisfies

⟨σ0σx⟩fτc ∼ Cd,R|x|−d/2, with Cd,R > 0, as |x| → ∞.

In d = 4, the kinetic operator is the spread-out Laplacian and the decay exponent is 2.
